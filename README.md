# 👤 LiteSocialProfile

LiteSocialProfile is a sleek and lightweight Android social profile app built using Kotlin and XML. It allows users to view and edit their profile information with smooth UI, dark/light theme toggle, and persistent data storage using SharedPreferences.

## 🚀 Features

- ✅ Splash Screen with Logo
- 👤 Profile Card with Name, Bio, and Rounded Image
- 📝 Edit Profile Screen with Validation
- 🎨 Light & Dark Theme Toggle
- 🖼️ Image Picker from Gallery or Camera
- 💾 Data saved using SharedPreferences
- 🍞 Custom Toasts and Beautiful UI

---

## 🧰 Tech Stack

- Kotlin
- Android XML (ConstraintLayout, CardView, etc.)
- SharedPreferences
- ActivityResultLauncher
- Material Design Components
